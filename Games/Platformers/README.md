# Platformer Levels

A small tkinter platformer with three handcrafted levels.

## Goal

Collect every gem, avoid traps, and reach the exit door to move to the next level.

## Controls

- Left / Right arrows or A / D: move
- Space or Up arrow: jump
- R: restart the current level

## Run

```bash
c:/Users/kanha/Documents/GitHub/BasicLearning/.venv/Scripts/python.exe platformer_game.py
```

## What is included

- Multiple levels with different platform layouts
- Traps that reset your progress when touched
- Collectibles that unlock the exit door
- A simple lives system and on-screen HUD
